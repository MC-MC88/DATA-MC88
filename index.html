How to use Data Factory

Mock data generator · MC88

Data Factory generates realistic mock datasets for testing dashboards, data models, prototypes and demos. Everything runs in your browser — no server, no sign-up, no data leaves your device.

Quick start

  1. Pick an industry sector — this defines the columns of your dataset.
  2. Pick a name culture — names, cities, phones and currency follow that culture.
  3. Set the row count using the input or the quick buttons.
  4. Optionally enter a seed to reproduce the same dataset every time.
  5. Toggle messy mode if you want dirty data for cleaning practice.
  6. Click Generate Dataset, then export in any format you need.

Presets

  1. Configure sector, culture, rows, seed and messy mode.
  2. Click Save preset and give it a name.
  3. Click any preset chip to restore it instantly.
  4. Click the × on a chip to remove it.

Custom schema import

  1. Click Import schema to load a JSON file with your own column names.
  2. Accepted formats: ["Col1","Col2"] or {"columns":["Col1","Col2"]}.
  3. Data is generated intelligently based on column names (ID, Name, Email, Price, Date...).
  4. The sector selector switches to Custom automatically.

Compare clean vs messy

  1. Enable messy mode first.
  2. After generating, click the Split view toggle.
  3. Clean data appears on the left, messy on the right — side by side.
  4. Perfect for teaching data cleaning or explaining what "dirty data" means.

Editable table

  1. Click any cell in the preview to edit it.
  2. Edited cells are marked with a small orange dot.
  3. Your edits apply to all exports and the full preview.
  4. Use arrow keys to move between cells, or Tab.

Session history

  1. Every generation is recorded automatically.
  2. Click the clock icon in the header to view your last 5 sessions.
  3. Click any entry to restore its settings and regenerate the same dataset.
